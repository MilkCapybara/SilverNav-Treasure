# 文档目录 / Documentation Directory

本目录包含项目的所有文档和说明文件。

## 文档分类

### 快速启动指南
- `QUICK_START.md` - 项目快速启动指南
- `BEHAVIOR_QUICK_START.md` - 船舶行为分析快速启动
- `ML_QUICKSTART.md` - 机器学习模块快速启动
- `QUICK_START_MIGRATION.md` - 数据迁移快速启动

### 迁移文档
- `MIGRATION_COMPLETE.md` - 数据迁移完成报告
- `MIGRATION_SUMMARY.md` - 数据迁移总结
- `MIGRATION_STATUS_NOW.md` - 当前迁移状态

### 技术文档
- `mac_clickhouse.md` - macOS 上 ClickHouse 配置指南
- `next_step_mongodb.md` - MongoDB 集成下一步计划
- `REDIS_INTEGRATION_CHECKLIST.md` - Redis 集成检查清单

### 项目规划
- `ROADMAP.md` - 项目路线图
- `DOCUMENTATION_INDEX.md` - 文档索引
- `FINAL_REPORT.md` - 项目最终报告
- `课设适配性分析报告.md` - 课程设计适配性分析

## 文档导航

### 新手入门
1. 先阅读根目录的 `README.md` 了解项目概况
2. 查看 `QUICK_START.md` 快速启动项目
3. 根据需要查看具体模块的快速启动指南

### 开发者
1. 查看 `ROADMAP.md` 了解项目规划
2. 查看 `DOCUMENTATION_INDEX.md` 查找具体文档
3. 查看技术文档了解各组件配置

### 运维部署
1. 查看 `mac_clickhouse.md` 配置 ClickHouse
2. 查看 `REDIS_INTEGRATION_CHECKLIST.md` 配置 Redis
3. 查看迁移文档了解数据迁移流程
