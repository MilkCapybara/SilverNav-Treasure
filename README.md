# SilverNav-Treasure
SilverNav Treasure (银航宝) is a lightweight shipping finance risk platform integrating vessel, AIS, regulatory and financial data. It features ETL pipelines, ML-based risk scoring (XGBoost/LightGBM + SHAP), and interactive dashboards. Built with Python, Spark, PostgreSQL, MongoDB, and FastAPI to demonstrate an end-to-end data-to-decision workflow.
