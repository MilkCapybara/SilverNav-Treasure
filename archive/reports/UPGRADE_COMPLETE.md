## 🔄 基准日期同步机制

### 实现原理
```javascript
// 1. 大屏修改基准日期时保存到localStorage
localStorage.setItem("silvernav_base_date", iso);

// 2. 其他页面监听storage事件
window.addEventListener('storage', function(e) {
    if (e.key === 'silvernav_base_date') {
        updateBaseDateDisplay();
        reloadData();
    }
});

// 3. 页面加载时读取最新日期
const baseDate = localStorage.getItem("silvernav_base_date");
```
