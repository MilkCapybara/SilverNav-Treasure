## 📊 新增页面概览

本次更新为银航宝系统新增了两个重要的监控页面，完善了数据中台的监控能力。

### 1. ⚡ 实时监控大屏 (monitor.html)

**访问地址**: `http://localhost:8000/monitor`

**功能特性**:
- 📈 **API调用统计**: 实时展示API调用次数、成功率、失败率
- ⏱️ **响应时间分布**: 可视化展示不同响应时间区间的请求分布
- 🗄️ **数据库连接池监控**: PostgreSQL和MongoDB连接池状态实时监控
- 💻 **系统资源监控**: CPU、内存、磁盘使用率的圆形进度条展示
- ⚠️ **实时告警信息**: 系统告警信息实时滚动展示
- 🔥 **热门API端点**: Top 10 API端点调用统计
- 📡 **数据流量监控**: 入站/出站流量实时监控

**技术亮点**:
- 扫描线特效动画
- 实时数据更新（5秒刷新）
- 圆形进度条动画
- 渐变色彩和发光效果
- 响应式布局设计

---

### 2. 🎯 数据质量监控 (quality.html)

**访问地址**: `http://localhost:8000/quality`

**功能特性**:
- ✓ **质量维度评分**: 完整性、准确性、时效性、一致性四大维度
- 📊 **数据源质量概览**: PostgreSQL和MongoDB数据源质量分析
- 📈 **质量趋势图**: 近30天质量趋势可视化
- 🗂️ **数据表质量检查**: 核心表的空值率、重复率、质量分统计
- ⚠️ **异常数据统计**: 空值异常、格式错误、重复记录、逻辑冲突统计
- ⏰ **数据时效性监控**: 各数据源最后更新时间监控
- 📋 **数据质量规则**: 质量规则检查结果展示
- 💡 **质量改进建议**: 智能化的质量改进建议（高/中/低优先级）

**技术亮点**:
- 数据流动特效动画
- 综合质量分徽章
- 多维度质量评分卡片
- 表格式质量检查列表
- 优先级标签系统
- 响应式布局设计

## 🚀 使用方法

### 1. 从Dashboard导航

在总览大屏 (dashboard.html) 页面，点击右下角的**页面导航按钮**，会弹出导航面板，包含以下选项：

- 📊 船舶行为分析
- 🚢 船舶画像
- 🔗 数据血缘
- ⚡ **实时监控大屏** (新增)
- 🎯 **数据质量监控** (新增)

### 2. 直接访问

启动应用后，可以直接访问：

```bash
# 启动应用
python main.py

# 访问实时监控大屏
http://localhost:8000/monitor

# 访问数据质量监控
http://localhost:8000/quality
```

### 3. 返回Dashboard

两个页面左上角都有**返回大屏**按钮，点击即可返回总览大屏。

## 🔧 技术实现

### 前端技术
- **HTML5**: 语义化标签
- **CSS3**: Flexbox/Grid布局、动画、渐变
- **JavaScript**: 原生JS，无框架依赖
- **Canvas**: 用于图表绘制（预留接口）

### 后端路由
```python
@app.get("/monitor", response_class=HTMLResponse)
async def monitor(request: Request):
    """实时监控大屏"""
    return templates.TemplateResponse("monitor.html", {"request": request})

@app.get("/quality", response_class=HTMLResponse)
async def quality(request: Request):
    """数据质量监控页面"""
    return templates.TemplateResponse("quality.html", {"request": request})
```

### 数据更新机制
- **实时监控**: 5秒自动刷新
- **数据质量**: 10秒更新指标，30秒更新表质量，60秒更新时效性
