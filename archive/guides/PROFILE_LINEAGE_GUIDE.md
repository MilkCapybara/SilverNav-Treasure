# 船舶画像与数据血缘功能说明

## 📋 功能概述

本次更新为银航宝系统新增了两个重要功能模块：

1. **船舶画像** - 综合船舶数据分析与画像展示
2. **数据血缘** - 数据流转与依赖关系追踪（预留接口）

---

## 🚢 船舶画像功能

### 访问地址
- URL: `http://localhost:8000/profile`
- 导航: 大屏右下角 → 页面导航 → 船舶画像

### 数据源
- **MongoDB**: `ais_tracks`（AIS轨迹数据）、`vessel_analysis`（船舶分析结果）
- **PostgreSQL**: `vessels`表（船舶基本信息）

### 核心功能

#### 1. 总览统计
- 船舶总数
- 活跃船舶数（近7天有轨迹）
- 船舶类型统计
- 船旗国统计

#### 2. 可视化图表
- **船舶类型分布饼图**: 展示前8种船舶类型的占比
- **船旗国分布饼图**: 展示前8个船旗国的占比
- **活跃度Top10表格**: 显示轨迹点数最多的10艘船舶
- **速度分布柱状图**: 展示不同速度区间的船舶数量

#### 3. 船舶详细画像
- 支持通过IMO编号搜索船舶
- 展示船舶基本信息（IMO、船名、类型、船旗国）
- 展示航行统计（近30天轨迹点数、平均速度、最大速度）
- 展示最新位置（经纬度、更新时间）
- 展示资产信息（如果在PostgreSQL中有记录）

### 基准日期同步
- 船舶画像页面的数据基准日与大屏的基准日**完全同步**
- 在大屏修改基准日期后，船舶画像页面会自动更新
- 基准日期通过localStorage实现跨页面同步

### API接口

#### GET /api/profile/overview
获取船舶画像总览数据
- 参数: `base_date` (可选)
- 返回: 船舶总数、活跃船舶数、类型分布、船旗国分布

#### GET /api/profile/vessel/{imo_number}
获取指定船舶的详细画像
- 参数: `imo_number` (必需), `base_date` (可选)
- 返回: 船舶基本信息、航行统计、最新位置、资产信息

#### GET /api/profile/statistics
获取船舶画像统计数据
- 参数: `base_date` (可选)
- 返回: 活跃度Top10、速度分布

## 🔧 技术实现

### 后端
- **框架**: FastAPI
- **数据库**: MongoDB + PostgreSQL
- **API设计**: RESTful风格
- **数据序列化**: 自定义序列化函数处理ObjectId和datetime

### 前端
- **原生JavaScript**: 无框架依赖
- **图表**: 纯CSS + SVG实现
- **状态管理**: localStorage + window对象
- **样式**: CSS3 + CSS变量

### 数据同步
- 使用localStorage存储基准日期
- 监听storage事件实现跨页面同步
- 页面加载时自动读取最新基准日期

## 🚀 使用方法

### 1. 启动应用

```bash
# 方式1: 使用启动脚本
./start_app.sh

# 方式2: 直接使用uvicorn
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 2. 访问页面

1. 打开浏览器访问 `http://localhost:8000`
2. 登录系统
3. 进入大屏 `http://localhost:8000/dashboard`
4. 点击右下角"页面导航"按钮
5. 选择"船舶画像"或"数据血缘"

### 3. 使用船舶画像

1. 查看总览统计和图表
2. 在"船舶详细画像"区域输入IMO编号
3. 点击"搜索"按钮查看详细信息
4. 基准日期会自动与大屏同步

### 4. 修改基准日期

1. 在大屏左上角点击"数据基准日"
2. 选择日期
3. 船舶画像页面会自动更新数据

## 📊 数据指标说明

### 船舶活跃度
- 定义: 近30天内的轨迹点数
- 用途: 衡量船舶的航行频率和数据完整性

### 平均速度
- 单位: 节（knot）
- 计算: 近30天所有轨迹点速度的平均值

### 速度分布
- 区间: 0-5节、5-10节、10-15节、15-20节、20-25节、25-30节、30+节
- 用途: 分析船舶速度特征

---

## ⚠️ 注意事项

1. **数据依赖**: 确保MongoDB中有ais_tracks数据
2. **基准日期**: 默认使用今天，可在大屏修改
3. **性能优化**: 大数据量时建议添加索引
4. **浏览器兼容**: 建议使用Chrome、Firefox、Safari最新版本
